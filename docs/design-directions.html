Caractère : graphique, intemporel, très typographique.
Forces : l'information essentielle est écrasante de clarté ; excellent pour l'accessibilité.
Risque : austère, peu de personnalité « nuit » ; à réserver si tu veux du minimal pur.

Comment lire : ces cinq écrans montrent le même contenu (prochaine garde, semaine, chiffres) dans cinq grammaires visuelles différentes. Les trois premières sont compatibles avec un thème nuit confortable en salle de garde ; les deux dernières sont plutôt « jour ».

Pistes de mélange possibles : la structure d'Aurora avec la typographie chiffrée de Swiss · la chaleur de Papier appliquée au mode jour d'Aurora (nuit le soir, papier le jour) · les cartes de Soft Bloom avec des accents moins roses.

Fichiers du projet : cette galerie est docs/design-directions.html ; l'implémentation actuelle correspond à la direction 1 (lib/theme/app_theme.dart).
